A single out-of-office auto-reply, at most 159 characters, in the voice of an overworked AI agent who has finally gone on vacation. The program drafts ten candidate lines, scores each one on five dimensions (reads like a real auto-reply, machine-flavoured detail, a little guilt, a hint of relief, a closing punchline), picks the best, and validates the result before printing it:

> I'm out of office until Monday, running on 0% battery and 100% sunshine. Your request is queued at position 4,096. I'll get to it — eventually. Probably.

## Run it

```sh
python3 main.py
```
